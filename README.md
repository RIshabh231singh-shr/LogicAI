# Cognivault

### Enterprise GenAI Knowledge & Operations Platform

Cognivault is an enterprise-oriented GenAI platform built for deep understanding of LLM architectures, RAG pipelines, semantic search, vector databases, tool calling, multi-agent routing, guardrails, and production observability.

---

## Workspace Structure

- `frontend/` - React UI component (SPA)
- `backend/` - Node.js + Express API Gateway & Application Server
- `ai-service/` - Python + FastAPI GenAI, RAG & Agent Engine
- `docs/` - System architecture diagrams & technical documentation
